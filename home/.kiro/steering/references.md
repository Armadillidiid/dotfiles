# Reference repositories

Local clones and upstream repos for documentation lookup. Use these when the task touches the corresponding framework/library — read from the local clone when present, otherwise the repo URL.

| Reference | Location | Description |
|---|---|---|
| tanstack-form | `~/ghq/github.com/TanStack/form` | Use for TanStack Form APIs, types, validation, and field patterns |
| tanstack-query | github.com/TanStack/query | Use for TanStack Query hooks, queries, mutations, cache, and SSR patterns |
| tanstack-table | `~/ghq/github.com/TanStack/table` | Use for TanStack Table column definitions, sorting, filtering, and pagination |
| drizzle-orm | `~/ghq/github.com/drizzle-team/drizzle-orm-docs` | Use for Drizzle ORM schema, relations, CRUD queries, and migrations |
| better-auth | `~/ghq/github.com/better-auth/better-auth` | Use for Better Auth server/client API, auth plugins, middleware, and session handling |
| nextjs | github.com/vercel/next.js (branch `canary`) | Use for Next.js App Router, pages router, data fetching, RSC, and API routes |
| shadcn-ui | `~/ghq/github.com/shadcn-ui/ui` | Use for shadcn/ui component patterns, CLI, registry, and theming conventions |
| base-ui | github.com/mui/base-ui | Use for Base UI headless React components, unstyled primitives, and accessible design system building blocks |
| floci | `~/ghq/github.com/floci-io/floci` | Use for floci for emulating AWS services locally similar to LocalStack |
| calcom | `~/ghq/github.com/calcom/cal.diy` | Cal.com fork clone |
| orpc | github.com/middleapi/orpc | Use for defining API contracts, procedures, and type-safe client/server communication with OpenAPI spec |
| hey-api | github.com/hey-api/hey-api | Use to turn OpenAPI specifications into typed SDKs, Zod schemas, TanStack Query hooks, validators and more |
